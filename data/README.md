# Test documents

Check each source's license before copying files into the repo. When unsure, commit a download script instead of the files.

| Set | Source | License | Committed? | Downloaded |
| --- | --- | --- | --- | --- |
| 1. Technical docs | FastAPI or Django documentation (Markdown on GitHub) | To confirm | Small sample in `data/samples/technical/` | |
| 2. Own files | Resume, project READMEs, notes | Private | No | |
| 3. Public policy | open.canada.ca publications | Open Government Licence - Canada (confirm per item) | Download script only | |
| 4. Long narrative | Project Gutenberg books | Public domain (confirm per book) | Download script only | |
| 5. Research papers | arXiv papers with a Creative Commons license | Per paper | Download script only | |

Files fetched by the download script go in `data/raw/`, which is git-ignored.
